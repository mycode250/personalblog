Module 03-2 Application Project

Data Visualization with ggplot2

The ggplot 2 is a plotting package that provides a powerful array of functions to create any charts from data. It provides a more programmatic interface for specifying what variables to plot, how they are displayed, and general visual properties. Therefore, we only need minimal changes if the underlying data changes or if we decide to change from one plot to another. This helps in creating publication-quality plots with minimal amounts of adjustments and tweaking. It is the ggplot2 package that makes R the king of data visualization tools and is included. It is no wonder ggplot2 is part of Tidyverse

In this module, you I was introduced to conceptsof the grammar of graphics when visualizing data with the ggplot2 package.
